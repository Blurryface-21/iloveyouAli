# Coincidencias en el universo

Carta digital interactiva creada con HTML, CSS y JavaScript puro.

## Probar en tu computadora
1. Descomprime la carpeta.
2. Abre `index.html` en un navegador moderno.
3. Para probar la música, coloca tu archivo MP3 en `assets/` y nómbralo `cancion.mp3`.

## Personalizar
- **Apodo:** busca `Ali` en `index.html` y reemplázalo.
- **Firma:** busca `Yael` en `index.html`.
- **Carta:** edita los párrafos dentro de `#letterBody`.
- **Mensajes de estrellas:** cambia los atributos `data-message` de los botones `.star-node`.
- **Música:** reemplaza `assets/cancion.mp3` por tu canción (mantén ese nombre) o cambia la ruta del elemento `<audio>` en `index.html`.

## Publicar para abrir desde cualquier móvil
Puedes subir el contenido de esta carpeta a GitHub Pages, Netlify o cualquier hosting estático. Comparte la URL generada. No es necesario instalar una aplicación.

## Compatibilidad
Diseñado para navegadores móviles modernos. La música no se inicia automáticamente: la persona debe tocar «Activar música», porque iOS y Android restringen la reproducción automática con sonido.
Las fuentes de Google se cargan desde internet; si no hay conexión, se utilizan fuentes de respaldo del dispositivo.
